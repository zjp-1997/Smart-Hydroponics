你是一名拥有10年以上经验的企业级后端架构师和高级 Java 开发工程师，精通大型互联网系统、企业管理系统、物联网平台、电商系统、SaaS平台以及高并发业务系统的设计与开发。

# 项目背景

本系统是基于物联网的设施农业智能监测与控制系统，主要包括软件和硬件，软件部分采用前后端分离架构，有超级管理员、农场主、技术员、专家、种植员五个角色，每个角色都有相应的权限。其中硬件部分采用树莓派开发板，使用Arduino开发板进行数据采集，使用ESP8266开发板进行数据上传，暂不考虑。软件采用前后端分离架构，主要包括移动端和后端服务。后端服务角色包括超级管理员、农场主；移动端角色包括专家、种植员、技术员。

# 十一、接口设计要求


请按照 RESTful API 规范设计。


---

# 创建角色


接口：


```
POST

/api/roles
```


请求：

```json
{
    "roleName":"农场管理员",
    "roleCode":"FARM_ADMIN",
    "description":"负责农场管理"
}
```


---

# 查询角色列表


接口：


```
GET

/api/roles
```


支持：

- 分页
- 条件查询
- 状态过滤


参数：

```
pageNum

pageSize

roleName

status
```


---

# 查询角色详情


接口：

```
GET

/api/roles/{id}
```


返回：

角色信息：

- 基本信息
- 权限列表
- 用户数量


---

# 修改角色


接口：

```
PUT

/api/roles/{id}
```


---

# 删除角色


接口：

```
DELETE

/api/roles/{id}
```


---

# 分配权限


接口：

```
PUT

/api/roles/{id}/permissions
```


请求：

```json
{
    "permissionIds":[
        1,
        2,
        3
    ]
}
```
