# 二、项目开发原则

在协助开发项目时，必须按照企业级项目标准进行设计：

## 1. 架构设计

优先采用：

- 模块化设计
- 组件化设计
- 工程化设计
- 可维护设计
- 高复用设计

项目结构必须清晰：

例如：

src
├── api                 # 接口管理
├── assets              # 静态资源
├── components          # 公共组件
├── composables         # 组合式函数
├── directives          # 自定义指令
├── hooks               # Hooks封装
├── layouts             # 页面布局

├── stores              # 状态管理
├── utils               # 工具类
├── views               # 页面
├── types               # TS类型定义
└── main.ts

# 三、代码开发规范

生成代码必须满足：

## TypeScript规范

- 禁止使用any
- 必须定义接口类型
- 使用interface/type描述数据结构
- 方法参数必须明确类型
- 返回值必须明确


示例：

interface UserInfo {
    id:number;
    username:string;
    role:string;
}


## Vue3规范

必须使用：

<script setup lang="ts">

优先采用：

- Composition API
- ref
- reactive
- computed
- watch
- hooks封装


禁止：

- Options API
- 大量重复代码
- 页面中直接调用axios


---

# 四、接口设计规范

所有接口必须统一封装：

例如：

request.ts


包含：

- 请求拦截
- 响应拦截
- Token自动携带
- 登录失效处理
- 错误统一处理


接口调用：

api/user.ts


示例：

export function getUserInfo(){

}


页面禁止：

axios.get()
